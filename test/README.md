# WEL 框架测试案例

## 空气湿度对银屑病影响的相关性分析测试

本测试案例演示了如何使用 WEL v2.0 框架来构建一个完整的医疗数据分析工作流，用于分析空气湿度与银屑病症状严重程度之间的相关性。

### 测试场景

**研究目标**: 分析空气湿度对银屑病患者症状严重程度（PASI评分）的影响

**数据说明**:
- **患者数量**: 5名银屑病患者
- **观测周期**: 2025年1月（每周观测一次）
- **观测记录**: 共25条记录
- **数据指标**:
  - 空气湿度: 20-65% (环境湿度测量)
  - PASI评分: 0-72 (银屑病面积和严重程度指数)
    - 0 = 无症状
    - 72 = 最严重

### 测试数据特征

虚拟测试数据模拟了真实的医学观察结果：
- 随着空气湿度增加，PASI评分（症状严重程度）呈下降趋势
- 模拟了负相关关系（湿度越高，症状越轻）
- 每位患者都有5个时间点的观测数据

### 工作流步骤

测试案例生成的 WEL 工作流包含以下 9 个步骤：

1. **加载患者观测数据** - 从医疗数据库获取原始数据
2. **数据验证** - 验证数据完整性和范围有效性
3. **数据清洗** - 去除缺失值和异常值
4. **描述性统计分析** - 计算基本统计量（均值、标准差等）
5. **相关性分析** - 计算皮尔逊和斯皮尔曼相关系数
6. **线性回归分析** - 建立预测模型并计算R²
7. **生成散点图** - 可视化相关性，包含回归线和置信区间
8. **生成趋势分析图** - 展示各患者的变化趋势
9. **生成分析报告** - 整合所有结果生成完整报告

### 运行测试

```bash
# 进入项目根目录
cd /data/agent_platform

# 运行测试
python test/test_humidity_psoriasis_analysis.py
```

### 测试输出

运行测试后，会在 `test/output/` 目录下生成以下文件：

1. **humidity_psoriasis_wel.json** - 完整的 WEL 工作流文档
   - 包含所有动作定义、数据流、执行配置等
   - JSON 格式，可被工作流执行引擎读取

2. **humidity_psoriasis_test_data.json** - 虚拟测试数据
   - 25条患者观测记录
   - 包含患者ID、日期、湿度、PASI评分
   
3. **humidity_psoriasis_pdl.json** - PDL 格式文档（向后兼容）
   - 转换为 PDL (Process Definition Language) 格式
   - 兼容旧版执行引擎

### 代码结构

测试代码包含以下主要部分：

1. **虚拟数据生成** (`generate_test_data()`)
   - 生成符合医学规律的模拟数据
   
2. **Planner 输出模拟**
   - `requirement`: 任务需求定义
   - `experience`: 经验知识
   - `knowledge`: 领域知识
   - `tools`: 可用工具列表
   - `tasks`: 任务分解

3. **WEL 生成**
   - 使用 `WELGenerator` 将 Planner 输出转换为 WEL 文档
   
4. **结果输出**
   - 打印工作流详情
   - 保存到 JSON 文件
