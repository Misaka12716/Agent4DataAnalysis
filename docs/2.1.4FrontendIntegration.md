# 2.1.4 多维度分析与大模型能力 — 前端联调入口

本文档面向 AgentPlatform 前端维护者，说明如何接入 **2.1.4 多维度分析与大模型能力支持**（`/psych/*`）。

完整接口字段、模块映射与请求/响应示例见权威文档：[**PsychAPI.md**](PsychAPI.md)（标题：《2.1.4…前后端对接接口文档》）。

## 3. 鉴权约定

同源 Demo 自动读取 `localStorage.agent_access_token`，也可在页内：

1. 填写手机号 → **发送验证码**（`POST /auth/send-sms-code`）→ 填入验证码 → **登录并联调**；
2. 或点 **验收登录**（`13800000000` / `888888`，需验收种子账号 / `ACCEPTANCE_MODE`）。

除登录外，所有 `/psych/*` 需：

```http
Authorization: Bearer <access_token>
Content-Type: application/json
```

文件下载接口不需要 `Content-Type`，但仍需要 `Authorization`。特征挖掘结果下载：`GET /psych/features/{feat_id}/download?format=csv|json`。

成功响应统一：

```json
{ "status": "success", "data": { } }
```

异步任务：提交后轮询 `GET /psych/tasks/{task_id}`，直至 `success` / `failed` / `cancelled`。

## 4. 启动与访问

```bash
bash scripts/start.sh
# 浏览器打开
# http://<host>:52716/psych-app
```

验收账号可选：`bash scripts/init-platform.sh --acceptance` 后按 [`StartInstruction.md`](StartInstruction.md) 使用联调手机号登录。
