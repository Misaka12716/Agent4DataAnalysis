# Planner 说明文档

## 功能简介
Planner 负责根据用户输入的目标或任务，自动生成多智能体协作的计划（Plan），并分配给各个 Agent 执行。它是多智能体系统中任务分解与流程编排的核心模块。

## 核心类与接口
- `Planner`: 负责接收任务请求，调用计划生成算法，输出可执行的计划。
- `Plan`: 表示一个具体的执行计划，包含多个步骤（Step）。
- `Step`: 计划中的单步任务，指定由哪个 Agent 执行、输入输出等信息。

## 主要流程
1. 用户或上游模块提交任务目标。
2. Planner 解析目标，调用计划生成逻辑，输出包含多个步骤的 Plan。
3. Plan 下发给调度器或直接分配给各 Agent 执行。
4. 支持计划的动态调整与回溯。

## 相关配置

- 可扩展不同类型的 Step 与 Agent
